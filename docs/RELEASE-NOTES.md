# 1.1.0 — unreleased draft

The offline rehearsal prepares Attestamp's local setup, contributor workflow and
distribution checks for review. Local coding-client discovery requires an explicit
selection and consent; ambiguous configurations remain unchanged. OFF stops new
capture, and provider Send stays under the provider client's control.

Development builds use ad-hoc signatures and are not notarized or Store-distributed.
Version and sequence are draft inputs inherited from the existing release example,
not an announcement or authorization. The browser version remains 2.3.5 and frozen
protocol/evidence identities remain unchanged. Historical evidence is preserved.

Installed vendor hook trust/emission, signed custody/distribution, Mozilla persistent
installation and Store/publication actions remain separate gates. Fixtures do not
prove authorship, provider receipt, complete history or pre-egress protection.
